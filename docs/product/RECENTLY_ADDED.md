# Recently added

Recently added is a Library view in the unlocked vault. Open **Library → Browse → Recently added**. It shows active photos, videos, audio, and files, with the most recently imported items first. Private notes remain in their own section.

The view uses the existing catalog import time and normal cursor pagination. It includes the full import history, without a date cutoff or item limit. Capture dates and file modification dates do not determine the order. Trash and quarantined objects are excluded by the ordinary Timeline query.

The order is fixed in this view. Media type filters, grid or list presentation, hidden thumbnails, the viewer, selection actions, and loading more items use the existing Library behavior. The Import action is available. When an import completes, the current query reloads so new items appear first when they match the active type filters.

Back first clears an active selection, then returns to All media. Opening another Library scope, an album, private notes, or a main destination leaves Recently added. The normal Library sort choice is retained. The view is session state and is not stored in public preferences or backups.

The feature adds no catalog fields, import history file, archive format, or encryption changes.
